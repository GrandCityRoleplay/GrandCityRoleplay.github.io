# Grand City Roleplay — Official Website

A static, mobile-friendly website for Grand City Roleplay.

## Files
- `index.html` — website structure/content
- `styles.css` — visual design
- `script.js` — Discord/game links and small interactions
- `assets/gcrp-logo.png` — GCRP logo

## IMPORTANT: add your real links
Open `script.js` and replace the `https://example.com` / `REPLACE_...` values with your real:
- Game link
- Global Discord
- Candidate Room 1
- Candidate Room 2
- Organisation Server 1
- Organisation Server 2
- Admin Server

## Customise organisations
The four organisation cards are placeholders in `index.html`. Replace their names/descriptions with your real organisations.

## Deploy
This is a static HTML/CSS/JS website, so it can be deployed to GitHub Pages or Cloudflare Pages.
